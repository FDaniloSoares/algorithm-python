# algorithm-python

Repositório pessoal de estudos de algoritmos e estruturas de dados em Python.

O objetivo aqui é praticar e registrar implementações feitas por conta própria,
sem depender de bibliotecas prontas, para entender como cada algoritmo funciona
por dentro.

## Conteúdo

Os arquivos são organizados por tema conforme os estudos avançam, por exemplo:

- Ordenação (bubble sort, insertion sort, merge sort, quick sort, ...)
- Busca (busca linear, busca binária, ...)
- Estruturas de dados (listas, pilhas, filas, árvores, grafos, ...)
- Recursão e programação dinâmica
- Exercícios diversos

## Como executar

Basta ter o Python 3 instalado e rodar o arquivo desejado:

```bash
python caminho/do/arquivo.py
```

## Observação

Este é um repositório de estudo. O código prioriza clareza e aprendizado,
não uso em produção.
